# WhoopSim

Plug in controller/drone transmitter to be able to move around as drone.
(Ive only tested bluetooth with an xbox controller & plugging in a radiomaster 
pocket)

Dependancies:
GLFW
freetype
glm
glew
OpenGL
OpenAL
homebrew:
openal-soft and libsnfile

To run:
mkdir build
cd build
cmake ..
make
./WhoopsnHoops
